# AI Agent Fundamentals

## Summary
An Agent is a system that leverages an AI model to interact with its environment in order to achieve a user-defined objective. It functions by combining reasoning, planning, and the execution of actions (often via external tools) to fulfill complex tasks.

## Key Ideas
*   **Agent Definition:** An Agent is an AI model capable of reasoning, planning, and interacting with its environment.
*   **The Agent Process:** The process involves receiving a command, understanding it (via natural language), engaging in reasoning and planning (determining steps and necessary tools), acting (executing the plan), and interacting with the environment.
*   **Core Components:**
    *   **The Brain (AI Model):** Handles reasoning and planning; decides which Actions to take based on the situation.
    *   **The Body (Capabilities and Tools):** Represents the Agent's equipped capabilities; the scope of possible actions is defined by the available tools.
*   **LLMs and Text:** Large Language Models (LLMs) are the most common AI model used, taking and outputting text.
*   **Tools vs. Actions:**
    *   **Tools:** External functionalities (e.g., a function or API call) that the Agent can utilize.
    *   **Actions:** The high-level task performed, which may require the use of multiple Tools.
