# AI Agents Study Guide

## Summary
This guide serves as a practical companion for the AI Agents course, helping learners understand how to build and deploy advanced agent systems. It contrasts the capabilities of a standard chatbot with those of an agent, which can use tools, plan, and maintain context. The course emphasizes building a small, working agent demo—such as a "course helper agent"—throughout the lessons to integrate concepts like planning, memory, and orchestration.

## Key Ideas
*   **Agent vs. Chatbot:** An agent goes beyond a chatbot by being able to read/search course files, use external tools (APIs, browsers), plan a learning path, maintain context, and provide traces/logs.
*   **Agent Components:** A complete agent system combines several parts:
    *   **Model:** The reasoning engine.
    *   **Tools:** Functions/APIs the agent can execute.
    *   **Knowledge:** Grounding data (e.g., course files).
    *   **Context:** Information included in the current model call.
    *   **Memory:** Information saved for later use.
    *   **Planning:** Breaking a large goal into smaller steps.
    *   **Orchestration:** Routing work across tools and steps.
    *   **Trust:** Safety, security, and observability measures.
*   **Practical Application:** The recommended approach is to follow a single demo idea (like the course helper) through the entire course, asking how each new lesson capability enhances the demo.
*   **Course Structure & Paths:** The course lessons (01-18) cover specific topics, and learners can jump into paths based on their goal (e.g., building a RAG agent, understanding multi-agent systems). Lessons 01-06 are crucial for beginners.
