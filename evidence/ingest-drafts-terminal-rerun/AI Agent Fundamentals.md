# AI Agent Fundamentals

## Summary
An Agent is a system that leverages an AI model to interact with its environment in order to achieve a user-defined objective. It functions by combining reasoning, planning, and the execution of actions (often via external tools) to fulfill complex tasks.

## Key Ideas
*   **Agent Definition:** An Agent is an AI model capable of reasoning, planning, and interacting with its environment.
*   **The Agent Process:** The lifecycle involves receiving a command, understanding it (via natural language), engaging in reasoning and planning (determining steps and tools), acting (executing the plan), and interacting with the environment.
*   **Core Components:**
    *   **The Brain (AI Model):** Handles the thinking—reasoning, planning, and deciding which Actions to take. The most common model is an LLM (e.g., GPT-4, Llama, Gemini).
    *   **The Body (Capabilities and Tools):** Represents the Agent's physical or digital capabilities and the tools it has been equipped with to execute actions.
*   **Actions vs. Tools:**
    *   **Tools:** External functionalities (e.g., a function to send an email) that the Agent can utilize.
    *   **Actions:** The high-level task performed by the Agent, which may require the use of multiple Tools.
