# AI Agent Fundamentals

## Summary
An Agent is a system that leverages an AI model to interact with its environment to achieve a user-defined objective. It combines reasoning, planning, and the execution of actions (often via external tools) to fulfill tasks.

## Key Ideas
*   **Definition:** An Agent is an AI model capable of reasoning, planning, and interacting with its environment.
*   **Agent Process:** An Agent receives a command, understands it (natural language), engages in reasoning and planning (figuring out steps/tools), acts (executes the plan), and interacts with the environment.
*   **Components:**
    *   **The Brain (AI Model):** Handles reasoning and planning; decides which Actions to take based on the situation.
    *   **The Body (Capabilities and Tools):** Represents everything the Agent is equipped to do; the scope of possible actions depends on the tools provided.
*   **LLMs as the Core:** The most common AI model is an LLM (e.g., GPT-4, Llama, Gemini), which takes and outputs text.
*   **Tools vs. Actions:**
    *   **Tools:** Additional functionality (like a code snippet or API call) that the Agent can use.
    *   **Actions:** The high-level task performed by the Agent, which may involve the use of multiple Tools.
*   **Agency Spectrum:** Agents exist on a continuous spectrum of increasing agency, from simple processors to multi-agent systems.
