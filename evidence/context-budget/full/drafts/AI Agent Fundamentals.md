# AI Agent Fundamentals

**Summary**
An AI Agent is a system that leverages an AI model to interact with its environment to achieve a user-defined objective. Analogized by "Alfred," the agent takes a natural language command, engages in reasoning and planning to devise a multi-step strategy, and then executes actions using specialized tools to fulfill the request. At its core, an agent combines a "Brain" (the AI model handling planning) and a "Body" (the capabilities and tools).

**Key Ideas**

*   **The Agentic Process:** An agent operates in a cycle: receiving a command, understanding the request (natural language), engaging in reasoning and planning to determine necessary steps, and finally acting upon the environment.
*   **Agent Architecture (Brain & Body):** The agent is composed of two parts: the "Brain," which is the AI model responsible for reasoning and planning; and the "Body," which represents the capabilities and tools the agent is equipped to execute actions.
*   **The Role of Tools and Actions:** While an Agent's goal is to perform an **Action** (the high-level task), it achieves this by utilizing **Tools**—specific functions or code implementations (e.g., `send_message_to`) that allow the agent to interact with its environment (e.g., generating an image or sending an email).
*   **Agency Spectrum:** Agents exist on a continuous spectrum of agency, ranging from a simple processor (where output has no impact on program flow) to a Multi-Agent system (where one agentic workflow can trigger another).
*   **Real-World Applications:** Agents are found in virtual assistants (Siri, Alexa), customer service chatbots, and dynamic Non-Playable Characters (NPCs), demonstrating the power of context-aware interaction.
