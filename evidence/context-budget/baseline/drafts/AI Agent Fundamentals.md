# AI Agent Fundamentals

## Summary
An Agent is a system that leverages an AI model to interact with its environment in order to achieve a user-defined objective. It achieves this by combining reasoning, planning, and the execution of actions, often through external tools.

## Key Ideas
*   **Definition and Agency:** An Agent is an AI model capable of reasoning, planning, and interacting with its environment. It possesses "agency"—the ability to interact with its environment.
*   **The Agent Process:** The process involves receiving a command, understanding it (via natural language), engaging in reasoning and planning (determining steps and tools), acting (executing the plan), and observing the environment.
*   **Core Components:**
    *   **The Brain (AI Model):** Handles reasoning and planning; decides which Actions to take based on the situation.
    *   **The Body (Capabilities and Tools):** Represents everything the Agent is equipped to do, defining the scope of possible actions.
*   **LLMs as the Engine:** The most common AI model is the LLM (e.g., GPT-4, Llama, Gemini), which takes and outputs text.
