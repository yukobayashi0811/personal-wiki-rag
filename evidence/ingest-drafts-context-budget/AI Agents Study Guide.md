# AI Agents Study Guide

## Summary
This guide serves as a practical companion for the AI Agents course, helping learners understand how to apply concepts, build a working agent demo, and connect ideas. It contrasts the capabilities of a sophisticated agent with a regular chatbot, detailing the components required for advanced agent systems and providing a structured approach to building and evaluating agents throughout the course.

## Key Ideas
*   **Agent vs. Chatbot:** An agent goes beyond a chatbot by being able to read/search course files, using tools, planning a learning path, maintaining context, remembering preferences, and showing traces/logs.
*   **Agent Components:** Advanced agent systems combine several parts: Model (reasoning engine), Tools (APIs, functions), Knowledge (grounding data), Context (current call info), Memory (saved info), Planning (breaking down goals), Orchestration (routing work), and Trust (safety/security).
*   **Course Workflow:** The course emphasizes a hands-on approach, suggesting learners follow a single demo idea (like a "course helper agent") through all lessons, applying each new capability to the demo.
*   **Technical Implementation:** The course samples use the Microsoft Agent Framework (MAF) targeting the Azure OpenAI Responses API, but also offers options like Foundry Local and MiniMax for different deployment needs.
*   **Lesson Focus:** Each lesson introduces a specific capability (e.g., Tool Use, RAG, Planning, Memory, Trust), and learners are encouraged to apply the concept to their demo and identify potential risks.
