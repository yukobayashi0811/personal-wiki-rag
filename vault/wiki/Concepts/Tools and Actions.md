# Tools and Actions

## Agent Body

The source describes the model as an agent's brain and its capabilities and tools as the body. The available tools limit the actions the agent can perform.

## Tools Versus Actions

Language models normally generate text, while developers add tools that let an agent affect its environment. An action is not the same as a tool because one action may require multiple tools.

Tool design materially affects agent quality, and a task may require either specialized or general-purpose tools.
