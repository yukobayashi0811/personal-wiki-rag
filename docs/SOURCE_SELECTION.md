# Source Selection Guide

The final project requires at least three original source documents. Select a small, coherent collection that supports a useful personal research theme.

## Source Requirements

Each source must:

- be a Markdown, plain-text, or text-extractable PDF file;
- contain material that may be included in a public GitHub repository;
- be free of credentials and unredacted private information;
- remain unchanged in `vault/raw/`;
- have enough substance to support factual retrieval and citation;
- be understandable without relying on a private external system.

## Preferred Collection

Choose three documents about one connected topic rather than three unrelated files. The collection should support:

1. one direct factual question answered by a single source;
2. one question phrased differently from the source text;
3. one question supported by a third source or by two sources together;
4. one plausible question that none of the sources can answer.

## Before Ingestion

For each source, record:

- title;
- author or owner, when known;
- why it belongs in the wiki;
- whether it is safe to publish;
- one expected supporting passage;
- one question the passage should answer.

The expected answers and test notes must stay outside `vault/` so the retrieval system cannot search its own answer key.
